# Setup — mcp-tomticket

```bash
npx -y mcp-tomticket
```

Set `TOMTICKET_TOKEN` in the MCP env block. Optional `TOMTICKET_BASE_URL` defaults to `https://api.tomticket.com/v2.0`.

Create the token in the TomTicket admin panel. Do not share it inside the skill zip.

Docs: https://github.com/glira/mcp-tomticket
